# Правила работы с репозиторием

- Сообщения коммитов — на русском языке.
- Ветка по умолчанию — `main`; изменения оформляются отдельной веткой и PR.
- Тесты: `poetry run pytest` (используется `config.settings_ci`, SQLite, eager Celery).
- Перед коммитом: `black`, `isort`, `flake8`, `pytest`.
- Секреты хранятся только в `.env` / `.env.docker` и GitHub Secrets; эти файлы не коммитятся.
- Покрытие в README указывается только по фактическому результату `pytest --cov`.
